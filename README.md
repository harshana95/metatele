# MetaTele

Project website for **MetaTele: Compact Refractive Metasurface Computational Telephoto Camera**.

- **Paper:** https://opg.optica.org/oe/fulltext.cfm?uri=oe-34-18-34880
- **Code:** https://github.com/harshana95/MetaTele-code

This repository hosts the GitHub Pages site (`index.html`, `css/`, `js/`, `images/`) only. Training and inference code lives in the separate [MetaTele-code](https://github.com/harshana95/MetaTele-code) repository.

## Development

The site is static HTML/CSS/JS with no build step. Open `index.html` directly in a browser, or serve the directory locally, e.g.:

```bash
python3 -m http.server 8000
```
